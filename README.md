# 💸 Dev-Convert Money

Um conversor de moedas simples, rápido e intuitivo desenvolvido para converter valores em **Real (BRL)** para **Dólar**, **Euro**, **Libra** e **Bitcoin**. 

Projeto desenvolvido durante as aulas do **DevClub**! 🚀

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura da aplicação.
- **CSS3**: Estilização moderna e layout responsivo.
- **JavaScript (ES6+)**: Lógica de conversão e manipulação do DOM (`Intl.NumberFormat`).

---

## ✨ Funcionalidades

- [x] Conversão instantânea de Real para Dólar (USD)
- [x] Conversão para Euro (EUR)
- [x] Conversão para Libra (GBP)
- [x] Conversão para Bitcoin (BTC) com suporte a 8 casas decimais
- [x] Alteração dinâmica de bandeiras/ícones das moedas ao selecionar no menu
